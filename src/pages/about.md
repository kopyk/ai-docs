At Zone 5 I write AS9100-compliant work instructions and build documentation for aerospace
programs, turning CAD models and engineering drawings into step-by-step procedures for
assemblers. Before that I was a Technical Writer at Gainwell Technologies (Feb 2025 – Feb 2026),
working on HIPAA EDI companion guides for DC Medicaid trading partners: I wrote the 837I v1.3
update and edited and enhanced the 276/277 v1.1 guide, both published on Gainwell's site (see
[Projects](/projects#gainwell-technologies-dc-medicaid-edi-companion-guides)). I have a B.A. in
English from the University of Houston (December 2025).

This site is where I show how I document AI systems and developer tools: a model card, a
tutorial, an API reference and an evaluation rubric, plus a maintenance work package and an
interface control document for defense and aerospace.

**Work status:** U.S. citizen; no current clearance; willing to undergo a background investigation.

## About these samples

All samples are original work written for this portfolio. Systems, part numbers and data are fictional.
No CUI, export-controlled (ITAR/EAR) or proprietary information is included.

Each sample opens with an **About this sample** box: who it's for, what kind of document it is,
how I approached it, and how it was checked.

## How this site is built

The site is built with [Docusaurus](https://docusaurus.io/). The tutorial's code and the API
reference's OpenAPI file are tested automatically on every change, along with the ICD byte layout,
the rubric's math and the model card's totals. The source is on
[GitHub](https://github.com/kopyk/ai-docs).
