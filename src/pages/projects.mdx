## ask-my-docs

<p className="proof-labels"><ProofLabel>56 tests · CI · Recall@4 10/10</ProofLabel></p>

A command-line tool that answers questions about a folder of Markdown documentation and cites
its sources. It finds the sections that match the question and sends only those to Claude, so
the answer comes from your docs.

I built it to learn retrieval-augmented generation (RAG) properly: not just to get answers, but
to measure whether retrieval finds the right section. It also runs as an MCP server, so Claude
Code and Claude Desktop can search a docs folder directly.

- 56 automated tests and a retrieval check run on every change, on Python 3.10 and 3.13.
- Retrieval finds the right file for 10 of 10 test questions within the top 4 sections.
- A changelog in the Keep a Changelog format.

[Repository on GitHub](https://github.com/kopyk/ask-my-docs). The
[tutorial on this site](/docs/ai/rag-tutorial) walks through a simplified version.

## Gainwell Technologies: DC Medicaid EDI companion guides

**Technical Writer, Gainwell Technologies · Feb 2025 – Feb 2026 · Irving, TX**

Companion guides tell Medicaid trading partners how to format HIPAA EDI transactions for a
specific program, here DC Medicaid fee-for-service. I wrote the 837I v1.3 update and
edited and enhanced the 276/277 v1.1 guide, working to the ASC X12 EDI 5010 standard. I also
reformatted the 276/277 guide into a cited, scannable Markdown version.

- Six companion guides for the Washington, D.C. EDI team reduced vendor onboarding questions by
  about 30%.
- Both guides are published on Gainwell's site.

## Jungle Decision Framework

A documentation site for a decision-making framework for jungling in League of Legends. It
covers macro play, tempo and information rather than champion mechanics, and it's organized so a
reader can start with simple, repeatable rules and work up: foundations, decision rules, a
decision tree, worked examples, common mistakes and a glossary.

I built it with Docusaurus. Its docs folder is also the frozen test corpus for ask-my-docs.

[docs.jordanyan.com](https://docs.jordanyan.com)
